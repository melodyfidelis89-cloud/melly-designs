# Melly Designs app starter

This is a responsive, installable web app (PWA) starter for Melly Designs. Customers can browse services and sample concepts, fill in an order request, and continue to WhatsApp at +234 812 516 9418.

## Included
- Responsive home, services, portfolio, about, and order sections
- WhatsApp order form with a pre-filled message
- Black-and-gold branding and app icon
- Web app manifest and basic service worker

## Preview locally
Open `index.html` in a browser. For PWA install/offline features, serve the folder over HTTPS or localhost (for example with a local development server).

## Before launch
1. Replace the sample portfolio concepts with your actual design work.
2. Add your final logo and confirm business details, terms, privacy policy, and contact information.
3. Test WhatsApp ordering on Android and iPhone.
4. Host the app on an HTTPS domain.
5. To publish in Google Play and Apple App Store, package the web app in a native app shell (for example, using Capacitor), create store assets, and submit it using eligible developer accounts. Store approval is not guaranteed.

This starter is not yet published to either store and does not process payments or upload files.
